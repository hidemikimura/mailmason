# スマホでの表示

Mailmason の出力は、PC とスマホで同じ HTML を使います。スマホ向けの見た目は、`<style>` のメディアクエリ（本文の幅以下の画面）で切り替えます。エディタのツールバーの「プレビュー」→「スマホ」で、幅 375px での表示を確かめられます。

## 自動で切り替わるもの

- 複数カラムの行は、スマホではカラムを縦に並べます（行の「スマホでは縦に並べる」をオフにすると横並びのまま）。
- 画像は画面の幅に合わせて縮みます。
- 画像＋テキストは、画像を先にして縦に並べます。
- ボタンの並び・画像ギャラリー・表は、ブロックの設定で縦に並べられます（[ブロック](./blocks)）。

## 表示する画面

行とブロックの設定パネルの「表示する画面」で、表示する画面を選べます（テンプレート JSON では `hideOn`）。

| 設定       | `hideOn`    | PC   | スマホ | Outlook（Windows） | メディアクエリに対応しないメールソフト |
| ---------- | ----------- | ---- | ------ | ------------------ | -------------------------------------- |
| すべて     | `null`      | 表示 | 表示   | 表示               | 表示                                   |
| PC だけ    | `"mobile"`  | 表示 | 隠す   | 表示               | 表示                                   |
| スマホだけ | `"desktop"` | 隠す | 表示   | 隠す               | **隠す**                               |

「PC だけ」「スマホだけ」にした要素には、キャンバスにバッジ（「スマホ非表示」「PC 非表示」）が付きます。キャンバスではどちらも表示します。

::: warning 「スマホだけ」の要素が表示されないメールソフト
「スマホだけ」の要素は、PC では隠しておき、メディアクエリでスマホのときだけ表示します。そのため、Outlook（Windows）と、メディアクエリに対応しないメールソフト（Gmail アプリで Gmail 以外のアカウントを使う場合など）では、スマホで開いても表示されません。

横長のバナーを PC 用とスマホ用で出し分けるような、どちらかが出れば足りる使い方に向いています。スマホの読者に必ず届けたい情報は「すべて」の要素に置いてください。
:::

- 「PC だけ」と「スマホだけ」の要素は、どちらもテキストパートに出ます。同じ内容を出し分けているときは、テキストパートを手直しして片方を消してください（[プレビューとテキストパート](./preview-and-text)）。
- 出力では、「スマホだけ」の要素の行（`<tr>`）に `display:none` を付け、Outlook 用の条件付きコメント（`<!--[if !mso]><!-->`）で囲みます。メディアクエリの `.mm-hide-desktop{display:table-row !important;}` で表示します。

## スマホの文字サイズ

スマホで文字を大きく（または小さく）できます。メディアクエリで上書きするため、Outlook（Windows）とメディアクエリに対応しないメールソフトでは PC と同じ大きさのままです。

- **メール全体**: 全体設定の「スマホの文字サイズ」（`body.settings.mobileFontSize`）。文字サイズを指定していないテキスト・表・画像＋テキスト・SNS のテキストリンクに効きます。見出しは本文との比（h1 は 1.75 倍、h2 は 1.4 倍、h3 は 1.2 倍）を保ちます。
- **ブロックごと**: テキスト・ボタン・ボタンの並び・メニュー・表の「スマホの文字サイズ」（`values.mobileFontSize`）。メール全体の設定より優先します。
- 空欄（`null`）のときは次のとおりです。
  - テキストと表で、文字サイズも空欄なら、メール全体の「スマホの文字サイズ」に従います。
  - 文字サイズを指定したテキスト・表と、ボタン・ボタンの並び・メニューは、PC と同じ大きさです。
- 行の高さは、PC と同じ倍率で文字サイズに合わせます。段落の間隔やボタンの余白は変わりません。

例: 本文 16px のメールで、スマホだけ 18px にする。

```json
{
  "body": {
    "settings": { "fontSize": 16, "mobileFontSize": 18 }
  }
}
```

出力では、要素に `mm-f18-29`（文字サイズ 18px・行の高さ 29px）のようなクラスを付け、メディアクエリに規則を加えます。使った大きさの分だけ規則が増えます。
