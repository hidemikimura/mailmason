## 画面の構成

| 場所               | 内容                                                                                                                  |
| ------------------ | --------------------------------------------------------------------------------------------------------------------- |
| ツールバー（上）   | 元に戻す・やり直す、編集 ⇄ プレビュー、プレビュー中は PC ⇄ スマホ。右端にはアプリのボタンを置ける（`slot="toolbar"`） |
| パレット（左）     | 「コンテンツ」タブにブロック、「行」タブに行のレイアウト                                                              |
| キャンバス（中央） | メール本体。配信される HTML と同じ見た目で表示する                                                                    |
| 設定パネル（右）   | 選択中の要素（全体・行・カラム・ブロック）の設定。上のパンくずで親の要素に移れる                                      |

## 追加する

- パレットの項目をキャンバスへ**ドラッグ**すると、挿入線の位置に置けます。ブロックを行の上下の端に落とすと、新しい 1 カラムの行になります。
- パレットの項目を**クリック**すると、選択中の要素の後ろ（何も選択していなければ末尾）に追加します。
- 画像ファイルをキャンバスに落としたり貼り付けたりすると、画像ブロックになります（アプリが[画像のアップロード](./images)を組み込んでいる場合）。
- パレットの「保存済み」タブから、保存しておいた行やブロック（[コンポーネント](./components)）を入れられます（アプリが組み込んでいる場合）。

## 選択して設定する

要素をクリックすると選択され、上にラベルと操作ボタン（上へ・下へ・複製・削除）が出ます。設定パネルで色・余白・文字サイズ・リンクなどを変えられます。「表示する画面」を「PC だけ」「スマホだけ」にした要素には、キャンバスにバッジ（「スマホ非表示」「PC 非表示」）が付きます（[スマホでの表示](./mobile#表示する画面)）。

## まとめて選ぶ

`Shift` または `Ctrl/⌘` を押しながら行やブロックをクリックすると、選択に加えます（もう一度クリックすると外します）。まとめて選べるのは行どうし、ブロックどうしです（行とブロック、カラムは混ぜられません）。

- まとめて選んだ要素には操作ボタンを出さず、設定パネルに件数と「複製」「コピー」「切り取り」「削除」のボタンを出します。
- `Delete` でまとめて削除、`Ctrl/⌘+D` でまとめて複製（それぞれのすぐ後ろ）します。元に戻すのは 1 回です。
- 並べ替え（`Alt+↑` / `Alt+↓`・ドラッグ）は、1 つだけ選んでいるときにできます。

## コピーして貼り付ける

選んだ行・ブロック（1 つでも、まとめて選んだものでも）を `Ctrl/⌘+C` でコピー、`Ctrl/⌘+X` で切り取り、`Ctrl/⌘+V` で貼り付けます。OS のクリップボードを使うので、別のタブや別のアプリで開いている Mailmason のメールにも貼り付けられます。

- 行は、選択中の要素を含む行の後ろ（何も選んでいなければ末尾）に貼り付けます。
- ブロックは、選択中のブロックの後ろ・選択中のカラムの末尾・選択中の行の最初のカラムの末尾に貼り付けます。何も選んでいなければ、新しい行にして末尾に入れます。
- 貼り付けた要素は ID を振り直し、選択された状態になります。元に戻すのは 1 回です。
- テキストの直接編集中や、設定パネルの入力欄では、ふつうの文字のコピー・貼り付けになります。
- 設定パネルの「コピー」ボタンは、ブラウザがクリップボードへの書き込みを許可しないと使えません。そのときは `Ctrl/⌘+C` を使ってください。

クリップボードには、行・ブロックのテンプレート JSON を次の形で入れます（`text/plain` と `application/x-mailmason+json`）。

```json
{
  "mailmason": "clipboard",
  "version": 1,
  "kind": "blocks",
  "items": [{ "id": "b_…", "type": "text", "values": {} }]
}
```

## 動かす

- 選択中の行・ブロックのラベル（つまみ）をドラッグすると、別の場所へ移せます。ブロックは別のカラムや新しい行にも移せます。
- `Alt+↑` / `Alt+↓` で 1 つずつ並べ替えられます。

## テキストを書く

テキストブロックは、選択中にもう一度クリックする（またはダブルクリック・`Enter`）とキャンバス上で直接編集できます。上に出る書式ツールバーで、段落の種類（本文・見出し 1〜3）、太字・斜体・下線・取り消し線、リンク、文字色、箇条書き・番号付きリスト、揃え、書式のクリア、差し込み変数の挿入ができます。差し込み変数は `{{` と入力しても候補が出ます（[差し込み変数](./merge-tags#入力中に候補を出す)）。

リンクは、文字を選んでツールバーの 🔗（または `Ctrl/⌘+K`）で URL を入力します。リンクの中にキャレットを置いて（または一部を選んで）開き直すと設定済みの URL が入っていて、そのまま書き換えるとリンク全体の URL が変わります。空にして適用するとリンクを外します。

他のアプリから貼り付けた文章は、メールで使える書式だけに整えます。`Esc` か、テキストの外をクリックすると編集を終えます。

## 表を編集する

表ブロックも、テキストと同じ操作（選択中にもう一度クリック・ダブルクリック・`Enter`）でキャンバス上で直接編集できます。クリックしたセルが編集中になり、上に書式ツールバー（太字・斜体・下線・取り消し線・リンク・文字色・書式のクリア・差し込み変数）が出ます。

- 別のセルをクリックすると、そのセルに移ります。`Tab` で次のセル、`Shift+Tab` で前のセルに移り、最後のセルで `Tab` を押すと行が増えます。
- `Enter` はセルの中の改行です（段落や見出し・リストは使えません）。
- 表の下のボタンで、編集中のセルの上下に行を、左右に列を挿入したり、行・列を削除したりできます（列は 8 列、行は 50 行まで）。
- `Shift` を押しながら別のセルをクリックすると、編集中のセルからそのセルまでの範囲を選びます。「セルを結合」で範囲を 1 つのセルにし（空でないセルの内容は改行でつなぎます）、「結合を解除」で元に戻します。結合したセルにかかる範囲は、結合したセル全体を含むまで広がります。
- 「行を上へ」「行を下へ」「列を左へ」「列を右へ」で、選んだ行・列を並べ替えます。編集中のセルの行の左端と列の上端に出るつまみをドラッグしても移動できます（落とせる位置に線が出ます）。縦に結合したセルの行（横に結合したセルの列）は、まとめて動きます。
- 列の幅（%）と揃え、見出し行・しま模様・罫線・セルの余白は設定パネルで変えます。

## キーボード

| キー                         | 動作                                                             |
| ---------------------------- | ---------------------------------------------------------------- |
| `Ctrl/⌘+Z`                   | 元に戻す                                                         |
| `Ctrl/⌘+Shift+Z`・`Ctrl+Y`   | やり直す                                                         |
| `Delete`・`Backspace`        | 選択中の要素を削除（まとめて選んだものも）                       |
| `Ctrl/⌘+D`                   | 選択中の要素を複製（まとめて選んだものも）                       |
| `Shift`・`Ctrl/⌘`+クリック   | 行どうし・ブロックどうしをまとめて選ぶ                           |
| `Ctrl/⌘+C` / `X` / `V`       | 行・ブロックをコピー / 切り取り / 貼り付け（別のメールにも）     |
| `Alt+↑` / `Alt+↓`            | 選択中の要素を並べ替え                                           |
| `Enter`                      | 選択中のテキスト・表を編集                                       |
| `Esc`                        | 編集を終える・選択を解除（狭い画面では開いているパネルを閉じる） |
| `Ctrl/⌘+V`                   | 画像の貼り付け（画像のアップロードを組み込んでいる場合）         |
| `Ctrl/⌘+B` / `I` / `U` / `K` | テキストの編集中: 太字 / 斜体 / 下線 / リンク                    |
| `Tab` / `Shift+Tab`          | 表の編集中: 次 / 前のセルへ                                      |
| `Shift+クリック`             | 表の編集中: セルの範囲を選ぶ（結合に使う）                       |

## 狭い画面

エディタの幅が 1024px 未満になると、キャンバスだけを表示し、パレットと設定パネルはツールバーの「追加」「設定」ボタンで重ねて開くようになります。判定はブラウザの幅ではなく**エディタ要素の幅**なので、サイドバーのあるアプリに組み込んだ場合も自動で切り替わります。
