## 画面の構成

| 場所               | 内容                                                                                                                  |
| ------------------ | --------------------------------------------------------------------------------------------------------------------- |
| ツールバー（上）   | 元に戻す・やり直す、編集 ⇄ プレビュー、プレビュー中は PC ⇄ スマホ。右端にはアプリのボタンを置ける（`slot="toolbar"`） |
| パレット（左）     | 「コンテンツ」タブにブロック、「行」タブに行のレイアウト                                                              |
| キャンバス（中央） | メール本体。配信される HTML と同じ見た目で表示する                                                                    |
| 設定パネル（右）   | 選択中の要素（全体・行・カラム・ブロック）の設定。上のパンくずで親の要素に移れる                                      |

## 追加する

- パレットの項目をキャンバスへ**ドラッグ**すると、挿入線の位置に置けます。ブロックを行の上下の端に落とすと、新しい 1 カラムの行になります。
- パレットの項目を**クリック**すると、選択中の要素の後ろ（何も選択していなければ末尾）に追加します。
- 画像ファイルをキャンバスに落としたり貼り付けたりすると、画像ブロックになります（アプリが[画像のアップロード](./images)を組み込んでいる場合）。

## 選択して設定する

要素をクリックすると選択され、上にラベルと操作ボタン（上へ・下へ・複製・削除）が出ます。設定パネルで色・余白・文字サイズ・リンクなどを変えられます。「スマホで非表示」にした要素には、キャンバスにバッジが付きます。

## 動かす

- 選択中の行・ブロックのラベル（つまみ）をドラッグすると、別の場所へ移せます。ブロックは別のカラムや新しい行にも移せます。
- `Alt+↑` / `Alt+↓` で 1 つずつ並べ替えられます。

## テキストを書く

テキストブロックは、選択中にもう一度クリックする（またはダブルクリック・`Enter`）とキャンバス上で直接編集できます。上に出る書式ツールバーで、段落の種類（本文・見出し 1〜3）、太字・斜体・下線・取り消し線、リンク、文字色、箇条書き・番号付きリスト、揃え、書式のクリア、差し込み変数の挿入ができます。

他のアプリから貼り付けた文章は、メールで使える書式だけに整えます。`Esc` か、テキストの外をクリックすると編集を終えます。

## キーボード

| キー                         | 動作                                                             |
| ---------------------------- | ---------------------------------------------------------------- |
| `Ctrl/⌘+Z`                   | 元に戻す                                                         |
| `Ctrl/⌘+Shift+Z`・`Ctrl+Y`   | やり直す                                                         |
| `Delete`・`Backspace`        | 選択中の要素を削除                                               |
| `Ctrl/⌘+D`                   | 選択中の要素を複製                                               |
| `Alt+↑` / `Alt+↓`            | 選択中の要素を並べ替え                                           |
| `Enter`                      | 選択中のテキストを編集                                           |
| `Esc`                        | 編集を終える・選択を解除（狭い画面では開いているパネルを閉じる） |
| `Ctrl/⌘+V`                   | 画像の貼り付け（画像のアップロードを組み込んでいる場合）         |
| `Ctrl/⌘+B` / `I` / `U` / `K` | テキストの編集中: 太字 / 斜体 / 下線 / リンク                    |

## 狭い画面

エディタの幅が 1024px 未満になると、キャンバスだけを表示し、パレットと設定パネルはツールバーの「追加」「設定」ボタンで重ねて開くようになります。判定はブラウザの幅ではなく**エディタ要素の幅**なので、サイドバーのあるアプリに組み込んだ場合も自動で切り替わります。
