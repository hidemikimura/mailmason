# Mailmason とは

Mailmason は、Web アプリに組み込んで使う **ノーコードの HTML メールエディタ** です。Lit 製の Web Components なので、フレームワークを問わず `<mailmason-editor>` を置くだけで使えます。

<ClientOnly>
  <MailmasonDemo template="basic" height="520px" :controls="false" />
</ClientOnly>

## できること

- **行 × カラム × ブロックでメールを組み立てる。** 行のレイアウトは 1 / 1:1 / 1:1:1 / 1:2 / 2:1 / 1:1:1:1 の 6 種類。ブロックはテキスト・画像・ボタン・区切り線・スペーサー・画像＋テキスト・画像ギャラリー・動画・ボタンの並び・メニュー・表・SNS リンク・QR コード・HTML の 14 種類です（[ブロック](./blocks)）。
- **ドラッグ&ドロップとキャンバス上での直接編集。** パレットから置き、つまみで並べ替え、テキストはクリックしてその場で書式を付けられます。
- **崩れにくい HTML を書き出す。** テーブル＋インライン CSS、XHTML 1.0 Transitional、Outlook 用の条件付きコメントと VML ボタン。スマホではカラムが縦に並びます。
- **マルチパート配信用のテキストパート。** 同じテンプレートから自動生成し、利用者が手で直すこともできます。
- **差し込み変数・プレビュー・画像のアップロード。** `{{name}}` のような差し込み変数、PC とスマホのプレビュー、ローカル画像のアップロード（保存先はアプリ側で決める）に対応しています。
- **TypeScript の型定義を同梱。** ブロックの値やイベントの `detail` まで型が付きます（[フレームワークで使う](./frameworks#typescript)）。
- **カスタムブロックとコンポーネント。** 独自のブロックを `defineBlock()` で追加でき（[カスタムブロック](./custom-blocks)）、作った行やブロックを保存して別のメールで再利用できます（[コンポーネント](./components)）。

## 考え方

**テンプレート JSON が唯一の正** です。エディタの表示、HTML、テキストパートはすべてテンプレート JSON から作ります。アプリが保存するのはこの JSON だけで、HTML とテキストは送るときに書き出します。HTML からテンプレートに戻す機能はありません。

```text
テンプレート JSON ──▶ エディタの表示
                 ├─▶ renderHtml   → 配信用 HTML
                 └─▶ renderText   → テキストパート
```

書き出しの関数（`@hidemikimura/mailmason/core`）は DOM に依存しないので、Node などのサーバーでも同じ HTML を作れます。

## 対象外のもの（v0.4）

- HTML からの取り込み、条件分岐・繰り返しの構文、テンプレートギャラリー、共同編集
- 画像の保存（アップロードの画面はあるが、保存先はアプリ側のフックで決める）

## 動作環境

Chrome・Edge・Firefox・Safari の最新版。エディタの画面幅は 1024px 以上を想定し、それより狭いとパレットと設定パネルは重ね表示になります。出力 HTML は Outlook（Windows）で表示を確認しています。
