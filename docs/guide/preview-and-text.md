# プレビューとテキストパート

## プレビュー

ツールバーの「プレビュー」で、配信用 HTML をそのまま表示します。「PC」は幅 900px（メールソフトの本文欄の目安）、「スマホ」は 375px で、スマホではカラムが縦に並び、「PC だけ」の要素が消えて「スマホだけ」の要素が出ます。スマホの文字サイズも反映します（[スマホでの表示](./mobile)）。

- 差し込み変数は候補の `sample`（無ければ `fallback`）で表示します。上部のチェックで、タグのままの表示にも切り替えられます。
- 上部に HTML の大きさ（KB）を表示し、90KB を超えると警告の色になります。
- プレビュー中は、見えない要素を誤って消さないよう、元に戻す・やり直す以外のショートカットを受け付けません。

アプリから切り替えることもできます。

```js
editor.view = 'preview'; // 'edit' | 'preview'
editor.previewDevice = 'mobile'; // 'desktop' | 'mobile'
editor.addEventListener('mm-view', (e) => console.log(e.detail)); // ツールバーで切り替えたとき
```

## テキストパート

マルチパート配信では、HTML を表示できない環境のためにテキスト版を一緒に送ります。Mailmason はテンプレートからテキストを自動で作ります。

| ブロック   | テキストでの形                                                                                                     |
| ---------- | ------------------------------------------------------------------------------------------------------------------ |
| テキスト   | 段落は空行で区切る。リストは `・` や番号付き、リンクは `文字 ( URL )`                                              |
| 画像       | `[代替テキスト] ( リンク先 )`（リンクが無ければ `[代替テキスト]`）。代替テキストが空の画像は飾りとみなして出さない |
| ボタン     | `▶ ラベル` と、次の行に字下げしたリンク先                                                                          |
| 区切り線   | `----------------------------------------`                                                                         |
| SNS        | `サービス名: URL` を 1 行ずつ                                                                                      |
| スペーサー | 出力しない                                                                                                         |

プレビューの「テキスト」タブで確認できます。

### ブロック・行ごとに扱いを変える

設定パネルの「テキストパート」で、ブロックと行ごとにテキストパートでの扱いを選べます。選ばなかったブロックは自動のままで、本文を変えるとテキストパートも変わります。

| 扱い                 | 内容                                                                                     |
| -------------------- | ---------------------------------------------------------------------------------------- |
| 自動（既定）         | 本文から作る                                                                             |
| 出さない             | テキストパートに出さない（ロゴなど飾りの画像に）                                         |
| テキストだけ         | HTML に出さず、テキストパートだけに出す（「HTML 版はブラウザでも見られます」などの文に） |
| 指定の文             | 書いた文を出す（下記）                                                                   |
| 行ごと出さない（行） | 行の中のブロックの設定にかかわらず、行ごと出さない                                       |

キャンバスでは、扱いを変えたブロック・行に印（「テキストに出さない」「テキストだけ」）を出します。「テキストだけ」のブロックも、直せるようにキャンバスには出します。設定パネルの「自動」の下には、そのブロックから作られるテキストを小さく見せます。

テンプレート JSON では、ブロックと行の `text`（`{ "mode": "hidden" }` など）に入ります。

### 指定の文と参照

「指定の文」では、そのブロックの今の値を `{@名前}` で参照できます。参照した値は書き出すたびに今の値で置き換えるので、ボタンの文字やリンク先を変えてもテキストパートが追いかけます。

```text
次の URL から、新しいパスワードを設定してください。
{@href}
```

| ブロック         | 参照できる名前                           |
| ---------------- | ---------------------------------------- |
| すべて           | `{@text}`（自動で作ったテキスト）        |
| 画像             | `{@alt}` `{@href}` `{@src}`              |
| 画像＋テキスト   | `{@alt}` `{@href}` `{@src}`（画像の値）  |
| ボタン           | `{@label}` `{@href}`                     |
| QR コード        | `{@content}` `{@alt}` `{@href}` `{@src}` |
| 動画             | `{@url}` `{@alt}`                        |
| カスタムブロック | 設定項目のキー（文字・数の値のもの）     |

「指定の文」に切り替えると `{@text}` から始まります（自動のときと同じ内容）。欄の下のボタンで参照を入れられ、差し込み変数（`{{キー}}`）も使えます。そのブロックに無い名前は書いたまま出し、設定欄と `mm-warning`（`unknown-text-ref`）で知らせます。

参照を 1 つも含まない文は本文と切れるので、指定したあとにそのブロックの内容が変わると「古い」とします（キャンバスの印「テキストが古い」、設定欄の案内、`mm-warning` の `stale-text` の `blockIds`）。設定欄の「確認済みにする」で消えます。

種類ごとに既定の書き方を決めるときは、`textOptions.textTemplates` に渡します。扱いが「自動」のブロックに使い、中身の無いブロック（ラベルの無いボタンなど）は出しません。

```js
editor.textOptions = { textTemplates: { button: '{@label}：{@href}' } };
```

### 全文を手で直す

「編集する」を押すと、テキストパート全体を手で直せます。全文を直すと、その後に本文を変えても自動では更新されないので、押したときに案内を出し、ブロックごとの設定でも直せることを伝えます（`textEditConfirm = false`、または属性 `text-edit-confirm="false"` で案内を出さずに始めます）。

本文が変わると「テキストの内容が本文と合っているか確認してください」という警告を出し、`mm-warning`（`stale-text`）を発火します。「確認済みにする」で警告を消し、「自動生成に戻す」で自動生成に戻ります。

### 書き出しのオプション

```js
editor.exportText({ wrapWidth: 70, headingPrefix: '■ ' });
```

プレビューと手直しの古さの判定にも同じ作り方を使うときは、`textOptions` に渡します（`exportText()` にも使います）。

```js
editor.textOptions = { textVariant: 'desktop', headingPrefix: '■ ' };
```

| オプション      | 既定値     | 内容                                                                                                                                                              |
| --------------- | ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `wrapWidth`     | `0`        | 折り返す桁数（全角 = 2 桁）。0 は折り返さない。URL は途中で折らない                                                                                               |
| `newline`       | `'\n'`     | `'\r\n'` も指定できる                                                                                                                                             |
| `headingPrefix` | `''`       | 見出しの前に付ける記号                                                                                                                                            |
| `dividerText`   | `'-'` × 40 | 区切り線の文字列                                                                                                                                                  |
| `mergeValues`   | `null`     | 差し込み変数に値を入れる                                                                                                                                          |
| `textTemplates` | `{}`       | 種類ごとの既定の書き方（`{ button: '{@label}：{@href}' }` など）                                                                                                  |
| `textVariant`   | `'both'`   | PC 用・スマホ用で分けたブロック・行（「表示する画面」）のどちらを出すか。`'both'` は両方、`'desktop'` はスマホだけのものを除く、`'mobile'` は PC だけのものを除く |

差し込み変数の値を配信システムで入れるときは、`wrapWidth` は 0（折り返さない）を勧めます。折り返しは `{{order_id}}` のようなタグの長さで数えるので、値を入れた後の幅とずれます。

サーバーでは `resolveTextPart(template, options)` を使います。手で直したテキストがあればそれを、無ければ自動生成を返し、`stale` で古さも分かります。`options` にはエディタの `textOptions` と同じ値を渡してください（違うと、手で直したテキストが「古い」と判定されます）。自動のときは、指定の文が古くなったブロックを `staleBlockIds` に、そのブロックに無い名前の参照を `unknownRefs` に返します。
