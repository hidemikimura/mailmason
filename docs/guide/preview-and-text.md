# プレビューとテキストパート

## プレビュー

ツールバーの「プレビュー」で、配信用 HTML をそのまま表示します。「PC」は幅 900px（メールソフトの本文欄の目安）、「スマホ」は 375px で、スマホではカラムが縦に並び、「PC だけ」の要素が消えて「スマホだけ」の要素が出ます。スマホの文字サイズも反映します（[スマホでの表示](./mobile)）。

- 差し込み変数は候補の `sample`（無ければ `fallback`）で表示します。上部のチェックで、タグのままの表示にも切り替えられます。
- 上部に HTML の大きさ（KB）を表示し、90KB を超えると警告の色になります。
- プレビュー中は、見えない要素を誤って消さないよう、元に戻す・やり直す以外のショートカットを受け付けません。

アプリから切り替えることもできます。

```js
editor.view = 'preview'; // 'edit' | 'preview'
editor.previewDevice = 'mobile'; // 'desktop' | 'mobile'
editor.addEventListener('mm-view', (e) => console.log(e.detail)); // ツールバーで切り替えたとき
```

## テキストパート

マルチパート配信では、HTML を表示できない環境のためにテキスト版を一緒に送ります。Mailmason はテンプレートからテキストを自動で作ります。

| ブロック   | テキストでの形                                                        |
| ---------- | --------------------------------------------------------------------- |
| テキスト   | 段落は空行で区切る。リストは `・` や番号付き、リンクは `文字 ( URL )` |
| 画像       | `[代替テキスト] ( リンク先 )`（リンクが無ければ `[代替テキスト]`）    |
| ボタン     | `▶ ラベル` と、次の行に字下げしたリンク先                             |
| 区切り線   | `----------------------------------------`                            |
| SNS        | `サービス名: URL` を 1 行ずつ                                         |
| スペーサー | 出力しない                                                            |

プレビューの「テキスト」タブで確認でき、「編集する」を押すと手で直せます。手で直したテキストは、その後に本文を変えても自動では更新されません。本文が変わると「テキストの内容が本文と合っているか確認してください」という警告を出し、`mm-warning`（`stale-text`）を発火します。「確認済みにする」で警告を消し、「自動生成に戻す」で自動生成に戻ります。

### 書き出しのオプション

```js
editor.exportText({ wrapWidth: 70, headingPrefix: '■ ' });
```

| オプション      | 既定値     | 内容                                                                |
| --------------- | ---------- | ------------------------------------------------------------------- |
| `wrapWidth`     | `0`        | 折り返す桁数（全角 = 2 桁）。0 は折り返さない。URL は途中で折らない |
| `newline`       | `'\n'`     | `'\r\n'` も指定できる                                               |
| `headingPrefix` | `''`       | 見出しの前に付ける記号                                              |
| `dividerText`   | `'-'` × 40 | 区切り線の文字列                                                    |
| `mergeValues`   | `null`     | 差し込み変数に値を入れる                                            |

サーバーでは `resolveTextPart(template, options)` を使います。手で直したテキストがあればそれを、無ければ自動生成を返し、`stale` で古さも分かります。
