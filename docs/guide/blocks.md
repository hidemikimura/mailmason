# ブロック

パレットの「コンテンツ」タブにある標準のブロックです。値の形は[テンプレート JSON](../reference/template#ブロック-blocks) を参照してください。アプリ独自のブロックは[カスタムブロック](./custom-blocks)で追加できます。

<ClientOnly>
  <MailmasonDemo template="content-blocks" height="620px" :controls="false" />
</ClientOnly>

| ブロック       | `type`      | 用途                                                                                                |
| -------------- | ----------- | --------------------------------------------------------------------------------------------------- |
| テキスト       | `text`      | 本文・見出し・リスト。キャンバス上で直接編集する                                                    |
| 画像           | `image`     | 画像 1 枚（リンク可）                                                                               |
| ボタン         | `button`    | 行動してほしいリンク。Outlook では VML の角丸ボタン                                                 |
| 区切り線       | `divider`   | 横線                                                                                                |
| スペーサー     | `spacer`    | 縦の空き                                                                                            |
| 画像＋テキスト | `imageText` | 画像と文章の横並び（スマホでは縦）                                                                  |
| 画像ギャラリー | `gallery`   | 画像を 2〜4 列の格子に並べる                                                                        |
| 動画           | `video`     | サムネイルに再生ボタンを重ね、動画のページにリンクする                                              |
| ボタンの並び   | `buttons`   | 複数のボタンを横に並べる（スマホでは縦）                                                            |
| メニュー       | `menu`      | 文字のリンクを区切り文字でつないで 1 行に並べる                                                     |
| 表             | `table`     | スペック・料金・日程などのデータの表。セルをキャンバス上で直接編集する                              |
| SNS リンク     | `social`    | SNS のアイコン（またはテキスト）のリンク                                                            |
| QR コード      | `qr`        | エディタが QR の PNG を作ってアップロードする（`onImageUpload` が必要。[画像](./images#qr-コード)） |
| HTML           | `html`      | 生の HTML をそのまま出力する（検証しない）                                                          |

## 表

1 行目を見出し（`th`）にした表です。セルには太字・斜体・下線・取り消し線・リンク・文字色・改行・差し込み変数を使え、段落・見出し・リストは使えません。編集のしかたは[エディタの操作](./editing#表を編集する)を参照してください。

- 列の幅は表に対する %（空欄の列は残りを等分）、揃えは列ごとに決めます。
- 見出し行の色、1 行おきの背景色（しま模様）、罫線の太さと色、セルの余白、文字サイズと文字色を設定できます。
- セルは縦・横に結合できます（`colspan` / `rowspan`。テンプレート JSON では `merges`）。結合したセルの幅は、結合した列の幅の合計です。
- 「スマホでの表示」を「縦に並べる」（`mobileLayout: "stack"`）にすると、スマホでは 1 行ずつ「見出し：値」の形に並べ替えます。列が多い表に向いています（[下記](#スマホで縦に並べる)）。
- テキストパートでは `サイズ | 着丈 | 身幅` のように `|` で区切り、見出し行の下に線を引きます。横に結合したセルは 1 つにまとめ、縦に結合したセルは各行に同じ値を出します。
- 出力はデータの表なので、スクリーンリーダーが表として読めるよう `role="presentation"` を付けません（レイアウトには使わないでください）。

### スマホで縦に並べる

「縦に並べる」にした表は、1 行目の見出しをラベルにして、2 行目以降を 1 行ずつ縦に並べます。たとえば「プラン・期間・料金・特典」の表の 2 行目は、スマホでは次のように表示します（行と行の間は少し空けます）。

| 見出し（ラベル） | 値       |
| ---------------- | -------- |
| プラン           | ライト   |
| 期間             | 月額     |
| 料金             | 500円    |
| 特典             | 初月無料 |

- 縦に結合したセルは、覆う行のそれぞれに同じ値を出します。横に結合したセルのラベルは、見出しを「 / 」でつなぎます。
- 見出し行が無い表は、ラベルを付けずに値だけを並べます。値がすべて空の行は出しません。
- 表と縦並びの両方を出力し、メディアクエリで切り替えます。Outlook（Windows）と、メディアクエリに対応しないメールソフト（Gmail アプリで Gmail 以外のアカウントを使う場合など）では表のまま表示します。
- 出力 HTML は、縦並びの分だけ大きくなります（本文 5 行 × 4 列でおよそ 5KB。Gmail は約 102KB を超えると本文を途中で省略します）。

## 動画

メールの中では動画を再生できないため、サムネイル画像に再生ボタンを重ねて、動画のページ（YouTube など）にリンクします。

- 動画の URL に YouTube の URL（`youtube.com/watch?v=…`・`youtu.be/…`・Shorts）を入れると、サムネイル（480×360 の `hqdefault.jpg`）を自動で入れます。自分で設定した画像は上書きしません。
- 再生ボタンは黒・白・なし。「なし」は画像ブロックと同じ出力（画像にリンク）になります。自社でボタン入りのサムネイルを作る場合に使います。
- 再生ボタンがあるときは、サムネイルをセルの背景に敷き、縦横比（16:9・4:3・1:1）に合わせてはみ出す分を切ります。Outlook（Windows）は VML で背景を敷きます。スマホでは画面幅に合わせて高さを変えます。
- 背景画像を表示しないメールソフト（Gmail アプリで Gmail 以外のアカウントを使う場合など）では、黒地に再生ボタンだけが出ます（リンクは効きます）。どのメールソフトでも同じ見た目にしたいときは、再生ボタン入りの画像を用意して「なし」を使ってください。

## 画像ギャラリー

画像を 2〜4 列の格子に並べます。画像ごとに代替テキストとリンクを設定できます。

- 「スマホでは 1 列に並べる」を有効にすると、スマホでは画像を縦に並べて画面幅いっぱいに広げます。無効（既定）なら、スマホでも格子のまま縮めて表示します。
- 画像の URL が空の項目は出力しません。

## ボタンの並びとメニュー

- **ボタンの並び**は、文字サイズ・角丸・内側の余白を共通にし、色はボタンごとに設定します。「幅をそろえる」でブロックの幅を等分します。「スマホでは縦に並べる」（既定で有効）では、スマホで 1 列に並べます。
- **メニュー**は、ヘッダーやフッターのナビゲーション向けです。区切り文字（既定は `|`、空なら空白）・間隔・文字の色と太さ・下線を設定できます。スマホでも 1 行に並べ、入らなければ折り返します。
- どちらもラベルが空の項目は出力しません。テキストパートでは 1 項目 1 行（`ラベル: URL`）にします。
